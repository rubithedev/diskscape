# diskscape

Walk through your File System

## Development Notes

Run this command to build and run this project:

```bash
zig build run
```

You would find really nice to use the `mise` zig version instead of your native one. It makes sure your version is the required `0.16.0` and not a development build that may break the build. Feel free to open an issue for build problems, though.

Install `mise-en-place` and run

```bash
mise install
```
